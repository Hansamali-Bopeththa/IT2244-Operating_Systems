01.File Viewing & Extraction Commands

vi DataFile.csv → Opens the file in vi editor for modification.

head DataFile.csv → Displays the first 10 lines of the file.

tail -3 DataFile.csv → Shows the last 3 lines of the file.

head -n3 DataFile.csv | tail -n1 → Extracts only the third row of the file.

02. Field Extraction Commands

awk -F, '{print $3}' DataFile.csv → Displays the third column (Age) using comma (,) as the separator.

cut -d, -f3 DataFile.csv → Similar to awk, extracts the third field.

03.Sorting Commands

awk -F, '{print $4}' DataFile.csv | sort → Sorts Salary column in ascending order.

awk -F, '{print $4}' DataFile.csv | sort -r → Sorts Salary in descending order.

sort -t, -k4 -n DataFile.csv → Sorts the file by Salary (column 4, numeric sorting).

sort -t',' -k4,4n DataFile.csv | sort -r → Sorts by Salary, then reverses order.
