02. Linux Commands
   Commands Used:
touch new.tsv → Creates an empty file named new.tsv.

vi new.tsv → Opens the file using the vi editor for editing.

ls -a → Lists all files, including hidden ones (. and ..).

cut -d$'\t' -f1 new.tsv → Extracts the first field from new.tsv, using tab (\t) as the delimiter.

cut -d " " -f3 new.tsv → Attempts to extract the third field using a space (" ") as the delimiter.
