# IT2244-Operating_Systems
This batch script is an Age Calculator, allowing the user to input their birth year and automatically computing their age based on the system’s current date.

![Age_Calculator](https://github.com/user-attachments/assets/5d569642-6b9e-471f-85dc-8d16ff21f576)

This batch script extracts and displays various date-related information from the system, including day, month, year, week of the year, and week of the month.
